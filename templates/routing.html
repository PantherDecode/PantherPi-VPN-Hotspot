ROUTING

Custom interface-to-interface rules, each with its own kill switch
Route traffic from any "distribution" interface (receiving client traffic - AP, LAN port, etc.) out through any "source" interface (providing internet - a VPN tunnel, WiFi client, wired uplink, etc.). Each rule has its own kill switch: if enabled and the source interface goes down, that rule's traffic is dropped entirely rather than falling back to leak out somewhere else.

Note: the distribution ("TO") interface needs its own IP/subnet already configured (e.g. a static IP you've set via the terminal) - this page routes traffic for it, it doesn't set that interface up from scratch.
